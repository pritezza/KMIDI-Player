# KMIDI Player 仕様書

最終更新: 2026-10-31（v1.0.0）

## 1. 概要

Windows 10 / 11 上で、追加のソフトウェアをインストールせずに動作する MIDI プレーヤー。
プレイリスト（ファイルリスト）を中心とした画面構成で、標準 MIDI ファイルを Windows の MIDI 出力デバイスで再生する。

## 2. 動作環境・技術構成

| 項目 | 内容 |
|---|---|
| 対象 OS | Windows 10（1903 以降）/ Windows 11 |
| アーキテクチャ | x64（64bit） |
| 言語 | C# |
| ランタイム | .NET Framework 4.8（OS 標準搭載のため追加インストール不要） |
| GUI | WinForms（ピアノロールの描画だけ、GPU で描くために WPF を使う。WPF も .NET Framework 4.8 に含まれ、追加インストールは不要） |
| 開発環境 | Visual Studio Community 2026（「.NET デスクトップ開発」ワークロード、.NET Framework 4.8 Targeting Pack） |
| MIDI 出力 | `winmm.dll`（`midiOutOpen` / `midiOutShortMsg` / `midiOutLongMsg`）を P/Invoke で呼び出す |
| 外部ライブラリ | 使用しない（NuGet パッケージにも依存しない） |
| 配布形態 | exe 単体（設定ファイルは実行時に生成） |

## 3. 対応ファイル形式

| 種類 | 対応 |
|---|---|
| 標準 MIDI ファイル（.mid）Format 0 / 1 | 対応 |
| Format 2、RIFF MIDI（.rmi） | 対象外 |
| RCP、MML などの独自形式 | 対象外 |
| プレイリスト（.m3u / .m3u8） | 読み込み・保存に対応（お気に入りの評価も読み書きする） |
| TMIDI Player のプレイリスト（.TO2） | 読み込みのみ対応（ファイルのパスだけを使う） |

- 曲名やトラック名などのテキストイベントは、Shift_JIS として解釈する（日本の MIDI データで一般的なため）。

## 4. 画面構成

│ ファイル(F)  再生(P)  表示(V)  設定(S)  ヘルプ(H)              │

│ [|◀] [▶/❚❚] [■] [▶|] [≡♪]  ━━━━━━━●━━━━━━━━━━   01:23 / 04:56   │
│ テンポ[100%] キー[ +0 ] モード[全曲リピート▼] [A][B] 評価[★★★☆☆ 以上] ベロシティ[╭╯ +2] リセット[GS▼] │
├──────────────────────────────────────────────────────────────┤

| 領域 | 内容 |
|---|---|
| 操作部（上段） | 前の曲・再生/一時停止・停止・次の曲、シークバー、経過時間/総時間、テンポ、キー、再生モード、A-B ループ、お気に入りの評価のフィルター、ベロシティカーブ、リセット種別 |
| プレイリスト（中段・メイン） | 番号、タイトル、演奏時間、お気に入りの評価、ファイル名。再生中の曲を強調表示する |
| チャンネルパネル（下段） | 16ch 分のトラック番号（TR）、送信先のチャンネル（CH）、ミュート（M）・ソロ（S）、鍵盤表示、ペダルのランプ、レベルメーター兼トラックごとの音量、トラックごとの移調・オクターブ。スプリッターで高さを調整でき、メニューから表示/非表示を切り替えられる |
| ステータスバー | 出力デバイス名、再生位置（時間・小節・拍）、今のテンポと拍子、ファイル形式、分解能（TPQN） |

- スピンボックス（テンポ、キー、チャンネルパネルの CH・移調・オクターブ、設定画面の数値）は、どれも同じ操作で値を変えられる。
  - ▲▼ ボタン、数値の直接入力（Enter キーまたは他の欄へ移ったときに確定）。
  - マウスホイール 1 目盛りで 1 段（テンポは 5%）。
  - 数値の欄を押したまま上下にドラッグ（上で増加、4px で 1 段）。3px 以上動かしたときにドラッグとみなし、動かさずに離せば普通のクリック（文字の入力）になる。最大・最小で止めても、戻せばすぐに反応する。

### 4.1 デザイン（配色）

- 画面は、立体の枠やグラデーションを使わないフラットデザインにする。配色は **ライト**（初期値）と **ダーク** の 2 つで、環境設定で切り替える（6.1）。

| 部分 | ライト | ダーク |
|---|---|---|
| 背景 / 一覧・チャンネルパネルの面 | 明るいグレー #F3F3F3 / 白 | 黒に近い紺 #15171C / #1B1E24 |
| 強調の色（再生ボタン、シークバー、鳴っている鍵、チェック、トグルのオン） | 青 #005FB8 | 緑 #3CCF91 |
| 再生中の曲の行 | 薄い青の地に濃い青の太字 | 濃い緑の地に明るい緑の太字 |
| 選んでいる行 | 薄いグレー | 少し明るい紺 |

- ボタン: 再生 / 一時停止は強調の色の円いボタン。前の曲・停止・次の曲・ピアノロールは枠の無いアイコン（マウスを乗せると地の色が付く）。A・B と「送信」は細い枠の角丸のボタン（A・B はオンの間、強調の色で塗る）。
- コンボボックス・数値の欄・評価のフィルター・ベロシティカーブ: 細い枠の角丸の欄。フォーカスがあると枠を強調の色にする。
- メニュー・右クリックメニュー・ツールバー・ステータスバー: 平らな地に、マウスを乗せた項目だけ角丸の地の色。チェックは強調の色の角丸の四角。
- 評価の星は、付いていない星も塗りつぶしの ★ を薄い色で描く。
- ミュート（橙）・ソロ（緑）・ペダルのランプ・レベルメーターの色は、意味を表す色なので配色によらず同じにする。
- ダークでは、タイトルバー（Windows 10 2004 以降・Windows 11）とスクロールバーも暗くする。Windows の設定で「タイトルバーにアクセントカラーを表示する」がオンのときは、その色のまま。
- ピアノロールは、ウィンドウのツールバーと右クリックメニューを配色に合わせる。絵の部分は表示の種類ごとの配色のまま（3D・円は暗い背景、横・縦は明るい背景）。

### 4.2 アプリのアイコン

- 角を丸めた青（ライトの強調の色 #005FB8 のグラデーション）の四角に、白い「KMIDI」の文字と、4 本の白鍵・2 本の黒鍵を描く。白鍵の 1 本を、鳴っている鍵としてダークの強調の色（緑 #3CCF91）で塗る。
- `src/KMidiPlayer/KMidiPlayer.ico` に 16・20・24・32・40・48・64・256px を入れる。
  - 16〜24px（タイトルバーなど）は、文字が読めないので鍵盤だけを大きく描く。
  - 16〜48px は、ぼやけないようピクセルに合わせて配置する。32px の文字はドット絵で描く。
- exe のアイコン（`ApplicationIcon`）にし、同じファイルを埋め込んでメイン画面のタイトルバーにも使う（WinForms では exe のアイコンがウィンドウに自動では使われないため）。ほかの画面（ピアノロール・環境設定・レベルメーターの設定）はアイコンを出さない。

## 5. 機能仕様

### 5.1 プレイリスト

- ファイルの追加方法: ドラッグ＆ドロップ（ファイル・フォルダ）、メニューの「ファイルを追加」「フォルダを追加」。
- フォルダを追加した場合は、配下の `.mid` ファイルをファイル名順に追加する。開けないサブフォルダ（ドライブ直下の System Volume Information など）は飛ばし、ほかのフォルダの曲は追加する。
- プレイリストの曲は絶対パスで持つ。起動時に相対パスで渡されたファイル（`KMidiPlayer.exe song.mid` など）は、起動したときのフォルダを元に絶対パスにする。
- 曲の削除、並べ替え（ドラッグ）、全消去ができる。
- ダブルクリックで、その曲を再生する。
- 再生中の曲の行は、背景に配色ごとの色（ライトは薄い青、ダークは濃い緑。4.1）を付け、文字を太字にする（選択中の行と重なった場合は、選択の色を優先する）。
  - 番号の左に再生状態の印を付ける: 再生中は ▶、一時停止中は ❚❚、停止中（曲の先頭）は ■。フォントの記号では大きさがそろわないので、図形で描く。
- タイトル列には、最初のトラックのシーケンス名（トラック名メタイベント）を表示する。無い場合はファイル名を表示する。
- 演奏時間は、追加時にファイルを解析して算出する。曲数が多い場合に画面が固まらないよう、バックグラウンドで処理する。
- 読み込めないファイルは、エラーとしてリスト上で区別して表示し、再生時にはスキップする。

### 5.1.1 プレイリストの右クリックメニュー

| 項目 | キー | 動作 |
|---|---|---|
| コピー | Ctrl+C | 選択した曲をクリップボードに入れる |
| カット | Ctrl+X | コピーしてから、リストから削除する（ファイルはそのまま） |
| 貼り付け | Ctrl+V | クリップボードの曲を、選択中の最後の曲の次に入れる。選択していなければ末尾に入れる。貼り付けた曲を選択する |
| リストから削除 | Delete | 確認してから、リストから削除する（ファイルはそのまま） |
| リストとファイルを削除... | Shift+Delete | 2 回確認してから、ファイルをごみ箱に移動し、リストからも削除する |

- 曲を選んでいないときは、貼り付け以外を使えなくする。貼り付けは、クリップボードに曲かファイルがあるときだけ使える。
- コピーした曲は、次のところに貼り付けられる。
  - このプレイリスト、ほかに起動した KMIDI Player のプレイリスト: 評価も引き継ぐ（独自のデータ形式 `KMidiPlayer.PlaylistItems` で、「評価 TAB パス」の行を入れる）。
  - エクスプローラー: ファイルのコピー。見つからないファイルは入れない。カットした曲でも、ファイルを移動せずにコピーにする（`Preferred DropEffect` をコピーにする）。
  - メモ帳など: ファイルのパスの文字列。
- エクスプローラーでコピーしたファイル・フォルダ・プレイリストファイルも、ドロップしたときと同じように貼り付けられる（MIDI ファイル以外は飛ばす）。
- リストとファイルを削除の確認:
  - 1 回目: パソコンからファイルを削除すること（ごみ箱に移動）と、削除するファイルのパス（10 個まで、残りは「ほか N 個」）を見せる。
  - 2 回目: 最終確認。どちらも「いいえ」を初めから選んでおく。
  - ごみ箱に入れられない場所（ネットワーク上など）では、完全に削除してよいかを Windows が尋ねる。
  - 同じファイルの曲がリストにほかにもあれば、それも削除する（評価のフィルターで隠している曲も）。
  - 使用中などで削除できなかったファイルの曲はリストに残し、そのファイルの一覧を表示する。

### 5.1.2 起動時に渡されたファイル

- exe に渡されたファイル（エクスプローラーの「プログラムから開く」、exe へのドラッグ＆ドロップ、コマンドライン）を、起動時に開いて最初の曲から再生する。
  - プレイリストファイル（.m3u / .m3u8 / .to2）が 1 つだけなら、「プレイリストを開く」と同じく今のリストを置き換える（上書き保存の対象にもなる）。
  - それ以外（MIDI ファイル、フォルダ、複数のファイル）は、プレイリストの末尾に追加する。
  - 渡した曲が隠れないよう、評価のフィルターを「すべて表示」に戻す。
- 起動中のアプリに渡す機能（二重起動の防止）はまだ無い。起動中に別のファイルを開くと、もう 1 つ起動する。

### 5.2 プレイリストの保存

- 終了時に現在のプレイリストを自動保存し、次回起動時に復元する。
  - 保存先は設定ファイルと同じフォルダの `KMidiPlayer.playlist.m3u8`。
  - 見つからないファイルも削除せず、読み込みエラーとして表示する。
  - 終了時に再生していた曲を、起動時に選択状態にする。再生ボタン（またはリスト上で Enter キー）で、その曲から再生できる。
    - 同じファイルが複数ある場合のために、プレイリスト上の位置とファイルパスの両方を記録する。位置の曲のパスが違っていれば、パスで探す。
    - 起動してから何も再生せずに終了した場合は、前回の記録を残す。
    - 再生位置（曲の途中）は記録せず、曲の先頭から再生する。
- メニューから M3U 形式で保存・読み込みができる。TMIDI Player のプレイリスト（.TO2）も読み込める。
  - 読み込み: `.m3u`（Shift_JIS。BOM 付き、または UTF-8 として正しく読める場合は UTF-8）、`.m3u8`（UTF-8）、`.TO2`（Shift_JIS）
  - 保存: UTF-8（`.m3u8` は BOM なし。`.m3u` に上書きする場合は、Shift_JIS と区別できるよう BOM 付き）。パスは常に絶対パスで書く（プレイリストファイルだけを別の場所へ移しても読めるようにするため）。
  - 「プレイリストを開く」は現在のリストを置き換える。プレイリストファイルをドラッグ＆ドロップした場合は、ドロップ位置に追加する（評価も引き継ぐ）。
  - 「プレイリストを保存」（Ctrl+S）は、開いた（または保存した）M3U ファイルに上書きする。M3U ファイルから開いていない場合（TO2 から開いた場合を含む）は、「名前を付けて保存」（Ctrl+Shift+S）と同じく保存先を尋ねる。
  - 開いているプレイリストファイルは設定に記録し、次回起動時も上書き保存の対象にする。
  - タイトルバーに、再生中の曲名と、開いているプレイリストファイルの名前を表示する（例: `♪ Field Map - 作曲家研究.m3u8 - KMIDI Player`）。曲を読み込んでいなければ曲名は出さない。最小化していても、タスクバーで今の曲がわかるようにするため。
  - `http://` などの URL の行と、MIDI ファイル以外（.mp3 など）は読み飛ばす。
  - 書かれた場所にファイルが無い場合は、ドライブやフォルダを移した可能性を考えて、パスの後ろの部分をプレイリストのフォルダにつないだ場所を、長いものから順に探す。
    - 例: プレイリストが `E:\MIDI\音楽研究室` にあり、`G:\古いフォルダ\作曲家研究\15世紀\曲.mid` が見つからない場合は、`E:\MIDI\音楽研究室\古いフォルダ\作曲家研究\15世紀\曲.mid`、`E:\MIDI\音楽研究室\作曲家研究\15世紀\曲.mid`… の順に探す。

### 5.2.1 お気に入りの評価

- プレイリストの「評価」列に、曲ごとの評価を 5 段階の星で表示する。初期値は未評価（☆☆☆☆☆）。
  - 星をクリックすると、その星までの数を評価にする。今と同じ数の星をクリックすると、未評価に戻す。
  - 星の上で押したまま左右に動かすと、マウスの位置に合わせて星が増減し、離したときの数を評価にする。最初の星より左で 0、5 つ目の星より右で 5。
  - 評価の欄の上で押したときは、行の選択やドラッグでの並べ替えは行わない（Shift・Ctrl を押しながらのクリックは、行の選択になる）。
  - 曲を選んで 0〜5 キー（テンキーも可）を押すと、選択中のすべての曲の評価を変える（0 は未評価）。
  - 星を続けてクリックしても、ダブルクリックとして曲を再生しない（2 回目のクリックで未評価にも戻さない）。
  - ちらつかないよう、評価を変えたときは評価の欄だけを描き直す。リストはダブルバッファーで描く。
- 評価は M3U ファイルに、曲のパスの前の行へ `#KMIDI-RATING:3` のように書く（未評価の曲には書かない）。`#` で始まる行なので、他のプレイヤーでは読み飛ばされる。
  - 自動保存のプレイリスト（`KMidiPlayer.playlist.m3u8`）にも書くので、評価は次回起動時にも残る。
- **フィルター**: A-B ループのボタンの右の「評価:」の星 5 つで、表示する曲を評価で絞り込む（0 = すべて表示、1〜5 = その数以上）。
  - 例: 星を 3 つにすると、評価 3 以上の曲だけを表示する。星の右に「すべて」（0 のとき）・「以上」（1〜4 のとき）を添える。
  - 操作はプレイリストの評価の星と同じ: クリックでその数（今と同じ数の星をクリックすると 0 = すべて）、押したまま左右に動かして選ぶ。リストの絞り込みは、ボタンを離したときに行う。
  - マウスホイールと ↑ ↓ キーで 1 ずつ、0〜5 キーでその数にする（← → は再生位置の移動のまま）。
  - 星の描き方は、プレイリストの評価の列と共通にする。
  - 番号（# 列）は、隠した曲も数えたプレイリスト全体での番号のまま表示する。
  - 再生（次の曲・前の曲・全曲再生・シャッフル）は、表示中の曲だけを対象にする。再生中の曲が隠れても再生は続け、次の曲はプレイリストの並びで次にある表示中の曲にする。
  - 評価を変えてフィルターの条件を下回った曲は、その場でリストから隠す。追加した曲（未評価）も、条件を下回れば表示しない。
  - 保存（上書き・名前を付けて・自動保存）は、隠した曲も含めたプレイリスト全体を保存する。
  - フィルターの選択は設定に保存する。
- **保存の確認**: 次の操作の前に、プレイリストファイルを開いた（保存した）ときから評価が変わっていれば、保存するかどうかを尋ねる（はい / いいえ / キャンセル）。
  - 対象の操作: アプリの終了、「プレイリストを開く」、「プレイリストを消去」。
  - M3U ファイルから開いている場合: 「『作曲家研究.m3u8』に保存しますか？」。はいで上書き保存する。
  - プレイリストファイルから開いていない場合（TO2 から開いた場合を含む）: 「プレイリストを保存しますか？」。はいで保存先を尋ねる（保存先の選択をキャンセルした場合は、操作も取りやめる）。
  - いいえを選ぶと、ファイルには保存せずに続ける（評価は自動保存のプレイリストには残る）。キャンセルを選ぶと、操作を取りやめる。
  - 評価を変えて元の値に戻した場合は、変わっていないものとして扱う。
  - 評価を保存していない間は、タイトルバーのファイル名の後ろに「*」を付ける。

### 5.3 再生操作

- 再生、一時停止、停止、前の曲、次の曲、シーク。
- 停止・一時停止・シーク・曲の切り替え時は、全チャンネルに All Sound Off（CC#120）、All Notes Off（CC#123）を送信し、音が鳴りっぱなしにならないようにする。
- シーク時は、移動先の時点までのプログラムチェンジ、コントロールチェンジ、ピッチベンドの状態を再現してから再生を再開する。
  - 後ろへ戻るとき（シーク・A-B ループ）は、戻り先から今までに音源へ送ったデータに、状態を送り直すだけでは戻せないものがあれば、自動リセットを送ってから曲の SysEx を初めから送り直す。戻せないもの: SysEx、戻り先までに一度も設定していない項目（CC・プログラム・RPN・NRPN）の設定（例: 終盤のフェードアウトだけで使う CC7）。Reset All Controllers で初期値に戻る項目（モジュレーション・エクスプレッション・ペダル・ピッチベンド・プレッシャー）は除く。
  - それ以外はリセットせずに送り直すだけにする（A-B ループのつなぎ目に、リセットの待ち時間を入れないため）。
- 同じチャンネルで同じ音高のノートが重なったときは、ノートオフで先に鳴った方から 1 つずつ止める（ノートオンのときの移調量で止める。途中でキーを変えても鳴りっぱなしにならない）。
- 出力デバイスは、設定メニューで選択する（システムに存在する MIDI 出力デバイスの一覧から選ぶ）。

### 5.3.1 再生位置の表示（TIME・BAR・BEAT）

- ステータスバー（出力デバイス名とファイル形式の間）に、再生位置を通常の文字で表示する（行を増やさず、プレイリストを狭くしないため）。

| 項目 | 形式 | 内容 |
|---|---|---|
| TIME | `00:01:23/45` | 時:分:秒/100 分の 1 秒（曲の上の時間。テンポを変えても曲の長さは変わらない） |
| BAR | `0012/0120` | 今の小節 / 全小節数 |
| BEAT | `03/04 0240/0480` | 今の拍 / 1 小節の拍数（拍子の分子）、拍の中のティック / 1 拍のティック数 |

- 小節と拍は、曲の拍子（メタイベント 0x58）とテンポ（0x51）から求める。拍子の指定が無ければ 4/4 拍子とする。
  - 1 拍の長さは拍子の分母の音符（6/8 拍子なら 8 分音符）。
  - 小節の途中で拍子が変わった場合は、そこから新しい小節として数える。
  - 曲の最後は、最後の小節の中として表示する（全小節数を超えないように）。
- 曲を読み込んでいないとき、SMPTE 形式（小節を数えられない）の曲では、BAR と BEAT をすべて 0 で表示する。
- 見出し（TIME・BAR・BEAT）はどの表示言語でも英語のまま。ツールチップに各値の意味を表示する。
- その右に、今のテンポと拍子を「♩=120  4/4」の形で表示する。
  - テンポは、曲のテンポにテンポ欄の % を掛けた実際の速さ（端数があれば小数 1 桁）。曲の途中のテンポ・拍子の変化にも追従する。
  - 曲を読み込んでいないとき、SMPTE 形式の曲では表示しない。

### 5.3.2 曲の頭の無音をとばす

- 「設定」メニューの「曲の頭の無音をとばす」（初期値: オン）がオンのとき、曲の先頭から再生する場合は、最初のノートの位置から再生する。
  - 対象: 曲の切り替え、1 曲リピートで先頭に戻ったとき、停止した後の再生（位置が 0 のときの再生）。シークで位置を指定した場合はとばさない。
  - それまでの音色・コントロールチェンジ・SysEx は、途中から再生するときと同じ方法で送る。先頭から再生するときと同じく、自動リセットを送り、曲の SysEx も初めから送り直す（1 曲リピートの 2 周目や、停止した後の再生でも）。
  - 無音が 0.3 秒より短い曲はとばさない。
- 設定に保存する。

### 5.4 再生モード・ループ

| モード | 動作 |
|---|---|
| 1 曲再生 | 現在の曲を再生して停止 |
| 1 曲リピート | 現在の曲を繰り返す |
| 全曲再生 | プレイリストを最後まで再生して停止 |
| 全曲リピート | プレイリストを繰り返す |
| シャッフル | プレイリストをランダムな順で再生する。全曲を一巡したら、順番を変えて繰り返す |

- 「次の曲」「前の曲」ボタンも再生モードに従う。
  - 全曲リピートでは、リストの端から反対側の端へ移る。
  - シャッフルでは「次の曲」でランダムに選び、「前の曲」で再生した履歴をさかのぼる。
- **A-B 区間ループ**: [A] ボタンで開始点、[B] ボタンで終了点を設定する。両方が設定されている間は、その区間を繰り返す。
  - [A] をもう一度押すと区間ループ全体を、[B] をもう一度押すと終了点だけを解除する。
  - A を設定せずに [B] を押した場合は、曲の先頭を開始点とする。
  - 区間はシークバー上に表示する。
  - 終了点より後へシークした場合は、ループせずにそのまま再生する。
  - 曲を切り替えると解除する。
- A-B 区間ループは、再生モードより優先する。
- MIDI ファイル内のループ位置情報（CC#111、`loopStart` / `loopEnd` マーカーなど）は読み取らない。

### 5.5 テンポ・キー変更

- テンポ: 25〜400%（初期値 100%）。曲中のテンポ変化に対する倍率として適用する。
- キー: -12〜+12 半音（初期値 0）。
  - 10ch（ドラム）は移調しない。曲データの 10ch（TR 10）と、送信先を 10ch にしたトラックの両方が対象。
  - 発音中にキーを変更しても音が残らないよう、ノートオフはノートオン時と同じ移調量で送信する。
- 移調後の音高が 0〜127 の範囲を外れるノートは送らない。
- 曲を切り替えたときに、テンポとキーを初期値へ戻すかどうかは設定で選べるようにする（初期設定: 戻す）。
- 再生位置と演奏時間の表示は、テンポを変えても曲の上での時間のままとする。

### 5.5.1 トラックごとの移調・オクターブ

- チャンネルパネルの各行（トラック）の、レベルメーターの右に「移調」と「オクターブ」のスピンボックスを置く。
  - 移調: -12〜+12 半音（初期値 0）。
  - オクターブ: -4〜+4（初期値 0）。1 で 12 半音ずらす。
- トラックの音の高さは「全体のキー + そのトラックの移調 + オクターブ × 12」だけずらす。
  - 10ch（ドラム）には全体のキーをかけないが、トラックごとの移調・オクターブはかける（明示的に指定したものなので）。
  - 全体のキーと同じく、変更は次のノートオンから反映し、ノートオフはノートオン時と同じ音高で送る。0〜127 の範囲を外れるノートは送らない。
- 曲を切り替えても保持する。アプリを終了すると元に戻る（保存しない）。
- チャンネルパネルの右クリックメニュー「移調とオクターブをすべて 0 に戻す」で、全トラックを初期値に戻せる。

### 5.5.2 トラックごとの音量

- 横幅を取らないよう、レベルメーターにボリュームのつまみを重ねる（メーターを縦に横切る線と、下辺の ▲）。
  - 範囲は 0〜150%（初期値 100%）。メーターの左端が 0%、右端が 150%（100% は 2/3 の位置）。
  - メーターの上をクリック・ドラッグして変える。マウスホイール 1 目盛りで 1% ずつ、ダブルクリックで 100% に戻る。
  - マウスを乗せている間と操作中は、ツールチップに値（「音量 80%」）を表示する。
- 曲のボリューム（CC#7）に倍率を掛けて送る。結果は 127 を上限とする（150% でも、元が 85 を超える分は頭打ちになる）。
  - ベロシティは変えない（音源によっては音色まで変わるため）。
  - 変えた瞬間に、そのトラックの送信先へボリュームを送り直す（伸ばしている音にもすぐ効く）。
  - 途中からの再生、A-B ループで戻ったとき、リセット（自動・手動・曲中の SysEx）の後は、100% 以外のトラックのボリュームを送り直す。曲でボリュームを指定していなければ 100 を元にする。
- レベルメーターは、倍率を掛けた後のボリュームで計算する（つまみを下げるとバーも短くなる）。
- 曲を切り替えても保持する。アプリを終了すると元に戻る（保存しない）。
- チャンネルパネルの右クリックメニュー「音量をすべて 100% に戻す」で、全トラックを初期値に戻せる。

### 5.5.3 ベロシティカーブ

- 評価のフィルターの右に、曲のすべてのトラック（ドラムを含む）にかけるベロシティカーブを設定するコントロールを置く。
  - 範囲は -12〜+12、初期値は 0（曲のまま）。
  - 今のカーブをグラフで表示し、右に値（例: `+2`）を出す。グラフには、0 のときの直線を薄い点線で重ねる。
  - 上にドラッグすると +、下にドラッグすると -（3px で 1）。マウスホイールと ↑ ↓ キーで 1 ずつ、ダブルクリックと Home キーで 0 に戻る。
  - ツールチップに、値とその効果（「弱い音を強めに」など）を表示する。
- 計算: 出力 = 127 ×（入力 ÷ 127）^γ、γ = 2^(-値 ÷ 8)。結果は 1〜127 に収める（127 は 127 のまま）。
  - + にするほど弱い音を持ち上げ（強弱の差が小さくなる）、- にするほど弱い音をより弱くする（強弱の差が大きくなる）。
  - 例: 入力 64 は、+12 で 100、+6 で 84、-6 で 40、-12 で 18。
- 変更は次のノートオンから反映する。鍵盤のクリックで鳴らす音にはかけない（押した位置でベロシティを決めているため）。
- レベルメーターは、カーブをかけた後のベロシティで計算する。
- 設定に保存し、次回起動時も引き継ぐ。

### 5.6 チャンネルのミュート・ソロ

- 各チャンネルにミュート（M）とソロ（S）を設ける。
- ソロが 1 つ以上オンの場合は、ソロがオンのチャンネルだけを鳴らす。
- ミュートしたチャンネルは、ノートオンを送らない。ミュートした瞬間に、そのチャンネルで鳴らしていた音のノートオフを送る。
  - All Sound Off / All Notes Off は送らない。音源によっては（HALion 7 など）、受け取ると他のチャンネルの音まで一瞬途切れるため。
  - そのため、ダンパーペダルを踏んだままの音は、ペダルが離されるまで余韻が残る。
- コントロールチェンジやプログラムチェンジは、ミュート中も送信する（解除時に音色や音量が正しい状態になるようにするため）。
- ミュート・ソロはトラック（TR）単位で設定する。

### 5.6.1 送信先のチャンネル（TR と CH）

- チャンネルパネルの各行は、曲データのチャンネル（1〜16）を「トラック（TR）」として表す。TR の番号は曲データのチャンネル番号と同じ。
- 各行の CH 欄（スピンボックス、1〜16）で、そのトラックの音を送る音源のチャンネルを変えられる。初期値は TR と同じ番号。
  - 入力は ▲▼ ボタン、マウスホイール（CH 欄を選んでいるとき）、数値の直接入力（Enter キーまたは他の欄へ移ったときに確定）。
  - 送信先を変えるのは、チャンネルメッセージ（ノート、コントロールチェンジ、プログラムチェンジ、ピッチベンドなど）だけ。SysEx はそのまま送る。
  - 複数のトラックを同じチャンネルに送ることもできる（その場合、音色やコントロールチェンジは後から送ったものが有効になる）。
- 再生中に送信先を変えた場合:
  - そのトラックで鳴っている音に、古い送信先でノートオフを送る。古い送信先を他のトラックが使っていなければ、ダンパーペダル オフ（CC#64 = 0）も送る。
  - その時点までの音色やコントロールチェンジ（シーク時と同じ内容）を、新しい送信先に送ってから再生を続ける。
- 停止・シーク・曲の切り替え時の All Sound Off / All Notes Off は、送信先を変えていても漏れがないよう、音源の 16 チャンネルすべてに送る。
- 送信先の設定は、曲を切り替えても保持する。アプリを終了すると元に戻る（保存しない）。
- チャンネルパネルの右クリックメニュー「CH（送信先）をすべて TR と同じに戻す」で、全トラックを初期値に戻せる。
- 1 行の高さはスピンボックス（CH・移調・オクターブ）が収まる高さより低くしない。全行が収まらない場合は、チャンネルパネルにスクロールバーを出す（マウスホイールでもスクロールできる）。見出しの行はスクロールしない。

### 5.7 鍵盤表示・レベルメーター

- 各チャンネルの鍵盤に、発音中のノートを点灯表示する（移調後の音高で表示する）。
  - ダンパーペダル（CC#64）を踏んでいる間にノートオフになった鍵は、ペダルを離すまで薄い色（強調の色を半透明で重ねる。ダークでは少し濃く）で点灯したままにする（ペダルで音が伸びていることを示す）。ペダルを離す（値 64 未満）と、そのチャンネルの薄い点灯をすべて消す。Reset All Controllers・リセットの SysEx・停止・シーク・曲の切り替えでも消す。
  - ペダルを音源に送らない設定にしていても、曲データどおりに表示する（ペダルのランプと同じ）。
- レベルメーターは、ノートオンのベロシティ、ボリューム（CC#7。トラックごとの音量を掛けた後の値）、エクスプレッション（CC#11）から算出し、時間とともに減衰させる。
- 表示の更新頻度は、レベルメーターの設定（下記）で決める。初期値は 30fps。

### 5.7.1 レベルメーターの設定

- 「設定」メニューの「レベルメーターの設定...」で開く画面で、次の項目を変えられる。値を変えるとすぐにメーターに反映し（見ながら調整できるように）、キャンセルすると元に戻す。

| 項目 | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| 更新頻度 | 10〜60 fps | 30 | チャンネルパネル全体（鍵盤・ペダルのランプを含む）の表示を更新する回数 |
| 表示タイプ | 下の 10 種類 | 単色バー | 一覧の各項目に、見本のメーターを描く |
| 下降速度 | 0.1〜3.0 秒 | 0.8 | メーターが 10% まで下がる時間 |
| ピークホールド | オン / オフ | オン | 直近の最大レベルの位置に、2px の印を残す（単色バーでは濃い青、それ以外ではその位置の色） |
| ホールド時間 | 0.2〜5.0 秒 | 1.5 | ピークの印を残す時間。過ぎたら、メーターと同じ速さで下がる |

- 表示タイプ（3 色は、左端から緑 → 70% の位置で黄 → 右端で赤）:

| 表示タイプ | 見た目 |
|---|---|
| 単色バー | 青いバー |
| グラデーション | 3 色のグラデーションのバー |
| LED（3 色） | 4px ごとに区切ったセグメント。位置によって 3 色で点灯し、消灯部分は薄い灰色 |
| LED（単色） | 同じセグメントを青で点灯 |
| ブロック | 8 つに区切った大きなブロック（3 色） |
| ドット | 丸い LED を並べたもの（3 色） |
| ハードウェア風 | 黒地に 3px の LED。消灯部分も暗い色で見える |
| 虹色 | 紫 → 青 → 緑 → 黄 → 赤のグラデーションのバー |
| 中央から左右 | 中央から両側へ伸びるバー（中央が緑、両端が赤）。ピークの印は左右に 1 本ずつ |
| 針 | レベルの位置に 3px の針だけを表示（位置の色） |

- ミュート中のチャンネルは、どの表示タイプでも灰色で描く。
- 「初期値に戻す」ボタンで、すべての項目を初期値に戻す（OK で確定）。
- 設定に保存し、次回起動時も引き継ぐ。
- 下降速度とピークホールドは実際の経過時間で計算するので、更新頻度を変えても下がる速さは変わらない。
- 「データのあるチャンネルだけ表示」（表示メニュー、初期設定: オン）がオンの場合は、曲の中でノートを鳴らすチャンネルだけを表示し、その分 1 行を高くする。
  - ソロ中のチャンネルは、ノートが無くても表示する（解除できるようにするため）。
  - 曲を読み込んでいないとき、ノートが 1 つも無い曲のときは、16 チャンネルすべてを表示する。
  - 1 行の高さには上限（60px）を設け、鍵盤が縦に伸びすぎないようにする。

### 5.7.2 ピッチベンド・モジュレーションの表示

- チャンネルパネルの、ペダルのランプとレベルメーターの間に「PB/Mod」の列を置き、2 本のバーで表示する。
  - 上段: ピッチベンド。中央に目盛りがあり、中央から右（+）または左（-）に伸びる（端が ±8192）。
  - 下段: モジュレーション（CC1）。左から伸びる（右端が 127）。
  - ミュート中のトラックは灰色で描く。
- マウスを乗せると、ツールチップに値（「ピッチベンド +4096　モジュレーション 100」）を表示する。
- 曲データの値を表示する（Reset All Controllers・リセットの SysEx で 0 に戻す。途中から再生するときは、その位置までの曲データから求め直す）。

### 5.7.3 鍵盤のクリック

- チャンネルパネルの鍵盤をマウスで押すと、その行の CH（送信先）のチャンネルにノートオンを送り、離すとノートオフを送る。
  - 押している間に CH を変えても、ノートオフはノートオンを送ったチャンネルに送る。
- ベロシティは、押した位置で決める。鍵の上端で 1、下端で 127 とし、その間は位置に比例させる（黒鍵は黒鍵自身の上端・下端で計算する）。
- 押したまま横にドラッグすると、同じチャンネルの別の鍵に移る（前の鍵は離す）。
- 押している鍵は点灯させ、レベルメーターにも反映する。
- 移調はかけない（鍵盤は移調後の音高で表示しているため、見た目どおりの音を鳴らす）。ミュート中のチャンネルでも鳴らす。
- 出力デバイスを切り替えるときは、押したままの音を止めてから切り替える。

### 5.7.4 ペダルのランプ

- 鍵盤とレベルメーターの間に、ペダルのランプを 3 つ並べる。並びは本物のピアノと同じく、左からソフト（CC#67）、ソステヌート（CC#66）、ダンパー（CC#64）。
- 曲データの値が 64 以上で点灯（オレンジ）、63 以下で消灯する。ミュート中のトラックは灰色で点灯する。
- マウスを乗せると、ツールチップにペダルの名前と CC 番号を表示する。
- 次の場合は消灯する: Reset All Controllers（CC#121）、リセットの SysEx（曲中・手動）、曲の読み込み。
  - 停止・シーク・曲の切り替え時は、音源にダンパーペダル オフを送るので、ダンパーのランプも消す。
  - 途中から再生するときは、その位置までの曲データからペダルの状態を求め直す。

### 5.7.5 ピアノロール

- 「表示」メニューの「ピアノロール」、または操作部の 1 段目（次の曲のボタンの右）のピアノロールのボタンで、別のウィンドウに開く・閉じる（メイン画面に付属するウィンドウ。メイン画面より手前に出て、最小化も一緒になる）。
  - ボタンは、開いている間は押し込まれた表示になる（A・B ボタンと同じ）。メニューのチェック・ボタン・ウィンドウの閉じるボタンの状態は常にそろえる。
- ウィンドウの上にツールバー、下に全体図を置く。ツールバーの項目は、ピアノロールの右クリックメニューにも同じものを並べる。

├──────────────────────────────────────────────┤
│                                              │
│              ピアノロール（表示の種類で描き方が変わる）     │
│                                              │
├──────────────────────────────────────────────┤
│▁▂▃ 全体図（曲全体の縮小図。枠が今出ている範囲）▃▂▁ │
└──────────────────────────────────────────────┘

#### 表示の種類

| 種類 | 描き方 | 再生位置 |
|---|---|---|
| 横 | 横軸が時間、縦軸が音の高さ。右から左へ流れる。左に縦の鍵盤、上に小節番号の目盛り | 左から 1/3 の縦線（固定） |
| 縦 | ノートが上から下の鍵盤へ落ちてくる。鍵盤は本物と同じく、白鍵を同じ幅で並べ黒鍵をその境目に置く | 下の鍵盤の上端 |
| 3D（初期値） | ノートが奥から手前の鍵盤へ流れてくる（遠近法）。ノートは厚みのある板として描き、奥ほど背景に溶かす。背景は暗い色 | 手前の鍵盤の上端 |
| 円 | 中心から外側の円い鍵盤へ広がる。角度が音の高さ（上の切れ目から時計回りに低い音から高い音）。背景は暗い色 | 鍵盤の輪の内側の円 |

- 音の高さは、曲で使っている音域（上下に 2 半音の余白、最小 2 オクターブ）に合わせる。移調・オクターブ（全体のキー、トラックごと）を反映した音の高さで描く。
  - 「88 鍵」をオン（初期値）にすると、音域を合わせず、ピアノの 88 鍵（A0〜C8）の幅で表示する（曲がはみ出すときは、そこまで広げる）。鍵盤の位置が曲によって変わらない。
- 鳴っている最中のノートは枠を付けるか明るくする。ミュート中（音を出さない）のトラックは灰色。
- 鍵盤は、鳴っている鍵をそのノートの色で塗る。C には音名（C4 など、ノート 60 = C4）を書く。
- 小節線（詰まるときは番号を間引く）を描き、A-B ループの区間を黄色で塗る。
- 時間方向の拡大率（1 秒あたり 20〜800px、初期値 100px）は全種類で共通。3D では何秒先まで描くかになる（100px で 5 秒先）。
  - ピアノロールの上のマウスホイール（1 目盛りで 1.25 倍）か、ツールバーの右端（全画面の左）の「倍率」のスライダーで変える。スライダーの右に、初期値を 100% とした倍率（20%〜800%）を表示する。
  - スライダーの目盛りは対数（どの倍率でも同じ感覚で動かせる）。クリック・ドラッグで変え、100% の目盛りの近く（4px 以内）では 100% にそろえる。スライダーの上のホイールと ← → ↑ ↓ キーで 1 段（1.25 倍）ずつ、ダブルクリックと Home キーで 100% に戻す。
  - ホイールで変えたときも、スライダーと倍率の表示を合わせる。

#### 色分けと音名

- 色分け（ツールバーの「色」）:
  - トラック別: トラック（チャンネル）ごとの色。暗い背景では、ドラム（10ch）を明るい灰色にする。
  - 強さ別: ベロシティカーブをかけた後のベロシティで、弱い = 青から強い = 赤まで。
  - 音名別（初期値）: C を赤にして、半音ごとに色相を 30° ずつ回す。
- 音名（ツールバーの「音名」）: なし / C D E（初期値）/ ドレミ（英語表示では Do Re Mi）。
  - ノートの中に、収まるときだけ音名を書く（オクターブは付けない）。鍵盤には、収まる白鍵すべてに書く（C はオクターブ付き）。
  - 「なし」のときは、鍵盤の C にだけ C4 などを書く。

#### エフェクト

- ノートが鍵盤（再生位置）に届いた瞬間に出すエフェクトの強さを、ツールバーの「エフェクト」（右クリックメニューにも同じもの）で、なし・1〜5 から選ぶ。初期値は 3。

| 強さ | 出すもの | 時間 | 火花の数 | 大きさ |
|---|---|---|---|---|
| なし | 出さない | — | — | — |
| 1（控えめ） | 広がりながら消える光と、火花 | 0.4 秒 | 6 | 1 倍 |
| 2 | 1 と同じ（多く・大きく） | 0.5 秒 | 10 | 1.25 倍 |
| 3 | ＋ 速く広がって消える衝撃の輪。火花を広く散らす | 0.6 秒 | 16 | 1.5 倍 |
| 4 | ＋ 鳴っている間、鍵盤から流れと逆の向きへ伸びる光の柱（揺らめく）。火花の一部を白くする | 0.7 秒 | 24 | 1.8 倍 |
| 5（派手） | ＋ 火花が尾を引く | 0.85 秒 | 36 | 2.2 倍 |

- 火花の向きと距離はノートごとに決まった乱数にし、曲の上の時間で描く（一時停止中は止まって見える。シークしても同じ絵になる）。
- 以前の設定（エフェクトのオン / オフ）は、オンを 1、オフを「なし」として読む（初期値の 3 ではなく、それまでの見た目のまま）。

#### 歌詞・マーカー

- 「歌詞・マーカー」がオン（初期値）のとき:
  - 今のマーカー（メタイベント 06。「A メロ」「サビ」など）を左上に出す。横・縦・3D では時間軸の上にも線と名前を、円では円を描く。
  - 歌詞（メタイベント 05）を上の中央に出す。今の行は、歌った所まで色を変え、次の行を小さく添える。
    - 行は、改行（\r・\n）、カラオケの MIDI の改行の印（行頭の / と \）、前の歌詞から 3 秒以上の空き、32 文字を超えるところで区切る。
    - 行を歌い終わって 4 秒たったら消す。次の行が 3 秒以内に始まるなら、先に出す。
  - 文字コードは Shift_JIS として読む。

#### 全体図

- 「全体図」がオン（初期値）のとき、ウィンドウの下に曲全体のノートを 1 本の帯に縮めて描く（色分けはピアノロールと同じ）。
- 今ピアノロールに出ている範囲を枠で、再生位置を赤い線で、A-B ループを黄色で、マーカーを上端の印で示す。
- クリック・ドラッグでその位置へ移動する（ドラッグ中は線だけを動かし、離したときに 1 回だけ移動する）。

#### 全画面

- ツールバーの「全画面」、右クリックメニュー、F11 キーで、ウィンドウのある画面いっぱいに表示する（枠とツールバーを消す）。Esc か F11 で元に戻る。
- 全画面の状態は保存しない（保存するウィンドウの位置と大きさは、全画面にする前のもの）。

#### 操作

- クリックでその位置へ移動（シーク）。鍵盤の上と、3D の一番奥より遠いところのクリックは無視する。
- 押したまま動かすと、ノートをつかんで動かすように再生位置を変える（横は左右、ほかは上下。流れる向きに引くと先へ）。3px 以上動かしたらドラッグとみなす。
  - ドラッグ中は表示だけを動かし、移動先の時間（分:秒.1/10 秒）を出す。ボタンを離したときに 1 回だけ移動する（動かすたびに移動すると、そのたびに音色などを送り直すため）。
  - 曲の先頭より前・最後より後には動かない。
- 表示の更新は、ピアノロールのウィンドウのタイマーで、ツールバーの「FPS」（右クリックメニューの「更新頻度 (FPS)」）で選んだ回数（15・24・30・45・60、初期値 30）だけ行う。ウィンドウを隠している間は止める。60 より大きい値が保存されていた場合は 60 にする。
  - WinForms の Timer は約 15.6ms 刻みでしか動かない（30fps を指定しても 21fps になる）ため、専用のスレッドで時間を測り（表示している間だけタイマーの精度を 1ms にする）、UI スレッドに描き直しを頼む。前の描き直しが終わっていなければ、その回はとばす。
  - 描くのが間に合わない場合（大きなウィンドウで音の多い曲など）は、選んだ回数より少なくなる。
  - 以前の設定（fps の項目が無いもの）は、レベルメーターの fps を引き継ぐ（以前はチャンネルパネルと同じタイマーで描き直していたため）。
- 描画は GPU（WPF の描画）で行う（初期値）。ピアノロールの上に WPF で描く子ウィンドウを重ね、横・縦・3D・円とエフェクトを、GDI+ のときと同じ描画のコード（描き先 RollCanvas を GDI+ 用と WPF 用で差し替える）で描く。
  - 子ウィンドウは表示だけにし、マウスの判定に「透過」と答えて、クリック・ドラッグ・ホイール・右クリックメニュー・ツールチップは下のピアノロールで受ける。
  - 右クリックメニューの「GPU で描く」でオン / オフを切り替える（設定に保存する）。オフ、または GPU を使えない環境（リモートデスクトップなど、WPF の描画がソフトウェアになる環境）では、今までどおり GDI+（CPU）で描く。使えない環境では、メニューの項目を選べなくする。
  - 計測（約 15,800 ノートの曲、1280×720、毎秒 60 コマ、プロセス全体の CPU 使用率）: GDI+ はどの表示でも 1 コアをほぼ使い切る（96〜99%）。GPU では横・縦・円で 25〜43%、3D で 39〜59%（エフェクト 3〜5）。
- ウィンドウを開いているかどうか、位置と大きさ、拡大率、表示の設定（種類、色分け、音名、エフェクトの強さ、FPS、88 鍵、全体図、歌詞・マーカー、GPU で描くかどうか）を設定に保存する。前回の位置がどの画面にも入らない場合は、メイン画面の近くに開く。

### 5.8 リセット送信

| 種別 | 送信する SysEx |

| GM System On | `F0 7E 7F 09 01 F7` |
| GS Reset | `F0 41 10 42 12 40 00 7F 00 41 F7` |

## 6. 設定

- 設定ファイル `KMidiPlayer.settings.xml` は exe と同じフォルダに XML 形式で保存する（フォルダごとコピーして持ち運べるようにするため）。
- exe のフォルダに書き込めない場合（`Program Files` 配下に置いた場合など）は、`%APPDATA%\KMIDI Player` に保存する。
- 保存する項目: 出力デバイス、配色、リセット種別、再生モード、ウィンドウ位置・サイズ、スプリッター位置、チャンネルパネルの表示状態、データのあるチャンネルだけ表示するかどうか、プレイリストの列幅、終了時に再生していた曲、テンポ・キーを曲ごとに初期化するかどうか、開いているプレイリストファイル、お気に入りの評価のフィルター、ベロシティカーブ、レベルメーターの設定、表示言語、音源に送らない CC、曲の頭の無音をとばすかどうか、常に手前に表示するかどうか、ピアノロールのウィンドウ（開いているか、位置・大きさ、拡大率、表示の設定）。
  - 「表示」メニューの「常に手前に表示」で、ウィンドウをほかのウィンドウより手前に表示する。
  - 出力デバイスは名前で記録する。次回起動時に見つからなければ、最初のデバイスを使う。
  - 前回のウィンドウ位置がどの画面にも入らない場合（モニターを外した場合など）は、画面中央に表示する。
  - ミュート・ソロ、テンポ・キーの値は保存しない。

### 6.1 環境設定（表示言語・配色）

- 「設定」メニューの「環境設定...」の「配色」で、**ライト**（初期値）と **ダーク** を選ぶ（4.1）。OK を押すと、アプリを再起動せずに、開いているすべての画面（ピアノロールも）に反映する。
- 「設定」メニューの「環境設定...」で、画面の表示言語を **日本語**（初期値）と **English** から選ぶ。
- OK を押すと、アプリを再起動せずに、その場ですべての画面の文字列（メニュー、ボタン、ラベル、一覧の項目、列の見出し、チャンネルパネルの見出し、ツールチップ、ステータスバー、タイトルバー、メッセージ）を切り替える。
  - コンボボックス（モード、リセット）の選択と、評価のフィルターの値は変えない。
  - 曲の読み込みエラーの理由は、読み込んだときの言語のまま表示する。
- 文字列は `Texts` クラスに、日本語と英語を並べて書く（`T("再生(&P)", "&Play")` の形）。画面のデザイナーには日本語を入れておき、起動時に表示言語のものに置き換える。
- 英語の表示では、評価のフィルターの星の右に「All」「& up」を添える。

### 6.2 音源に送らない CC

- 環境設定の「音源に送らない CC」の一覧（CC 0〜127、番号と名前つきのチェック付きリスト）で、チェックした CC を曲データから音源に送らない。全チャンネル共通。
  - 一覧の下に、送らない CC の番号をまとめて表示する（例: 「送らない CC: 64, 67」）。「すべて解除」ボタンで全部のチェックを外す。
  - 開いたときは、送らない CC のうち最初のものが見える位置までスクロールする。
- チャンネルパネルのペダルのランプを左クリックすると、そのペダルを音源に送る / 送らないを切り替える（どの行のランプでも、全チャンネル共通の設定を切り替える）。ランプの上ではカーソルを手の形にする。
- ランプを右クリックすると、メニューの先頭に「ソフトペダル（CC67）を音源に送らない」のような項目が出て、同じ設定を切り替えられる（チェックで送らない）。
  - 送らないペダルのランプには、赤い斜線を引く。曲データで踏まれていれば、ランプは点灯させたままにする。
  - ツールチップに、送るかどうかと操作を出す（例: 「ソフトペダル（CC67）: 音源に送る（クリックで送らない）」）。
- 送らない CC は次のものに効く: 曲データのコントロールチェンジ、途中から再生するときに送り直す状態、トラックごとの音量で送り直すボリューム（CC7）。
- 停止・シーク・送信先の変更のときにアプリ自身が送る音止め（CC120・CC123・ダンパーペダル オフ）は、設定にかかわらず送る（音が鳴りっぱなしにならないように）。
- オン / オフで使う CC（64〜69: ダンパー・ポルタメント・ソステヌート・ソフト・レガート・ホールド 2）を送らないようにしたときは、音源側で踏んだままにならないよう、全チャンネルにオフ（値 0）を 1 度だけ送る。
- 送らない CC も、レベルメーターやペダルのランプのために、曲データの値は追いかける。
- 設定に保存する（番号をカンマ区切りで記録）。
- 設定ファイルの項目が欠けていたり壊れていたりしても、その項目だけ初期値にして起動する。

## 7. 非機能要件

- **タイミング精度**: 再生専用スレッドを設け、`timeBeginPeriod(1)` と `Stopwatch` を使って、発音タイミングのずれを数 ms 以内に収める。
- **画面の応答性**: 再生処理と画面描画を分離し、画面操作中も再生が乱れないようにする。
- **異常系**: 出力デバイスが開けない、ファイルが壊れているなどの場合は、エラーメッセージを表示し、アプリは終了しない。
- **既知の制約**: Windows 標準の Microsoft GS Wavetable Synth は発音遅延が大きい。これは OS 側の制約であり、本アプリでは対処しない（外部音源・仮想音源の利用で回避できる）。
